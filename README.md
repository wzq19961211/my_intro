# 温 梓勤｜職務経歴プレゼンテーション

食品卸の法人営業で培った経験と実績を、図解で紹介する日本語プレゼンテーションです。

公開先：<https://wzq19961211.github.io/my_intro/>

## 操作方法

- 「説明を進める」または左右の矢印キーで、説明を順番に表示できます。
- 「前のページ」「次のページ」または Page Up / Page Down で、ページを切り替えられます。
- 目次から各ページに移動できます。「すべて表示」で、そのページの説明をまとめて表示できます。
- URL末尾の `#4.2` は「4ページ目・説明2」を表し、その状態を共有できます。

## 公開と更新

`index.html` はスタイル・図解・操作機能を含む単一ファイルです。ビルドや追加ライブラリは不要です。

GitHub Pages の公開元をブランチのルートに設定し、`index.html` と `.nojekyll` を配置すると公開できます。更新時は `index.html` を差し替えてください。

資料中の在籍状況・実績は、ページ内に記載した資料時点の情報です。
